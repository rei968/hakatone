# Mobile Client - MangoDota

Кроссплатформений мобільний застосунок **MangoDota** на **Flutter** (`dio`, `Riverpod`, локальний кеш у `Hive`).

## 💡 Для розробника Mobile (TY)
1. Усі готові тестові дані знаходяться тут:
   - `../backend/database/seeds/dota2.json` (герої з числовими id `14`, `8`, `74`, `attack_type`, `bio`, `stats`, скілами та білдами)
   - `../backend/database/seeds/meta.json` (актуальна мета та вінрейти)
2. Опис полів та структури API описаний у `../docs/openapi.yaml` (підтримує Gemini AI та повний контракт `HeroWithBuild`).
3. Коли бекенд підніметься (локально чи на Render), ви просто підставите `baseUrl` вашого API-сервісу у `dio`.

## 📱 Основні екрани (MVP):
1. **Splash**: логотип-манго, перевірка сесії.
2. **Екран авторизації**: вхід / реєстрація.
3. **Екран мети Dota 2**: список героїв за Tier (S, A, B, C), вінрейти, пікрейти, pull-to-refresh, індикатор «Оновлено X хв тому».
4. **Екран героя і білда**: картка героя (характеристики, скіли, AI-білд від Gemini).
5. **Кеш у Hive**: збереження отриманих даних для безперебійної роботи в офлайн-режимі.
