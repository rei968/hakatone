# Mobile Client - GameGuide

Кроссплатформений мобільний застосунок (довідник з комп'ютерних ігор).

## 💡 Важливо для розробника Mobile (Contract-First підхід)
Вам **НЕ потрібно чекати**, поки бекенд буде повністю готовий!
1. Усі готові тестові дані знаходяться тут:
   - `../backend/database/seeds/dota2.json`
   - `../backend/database/seeds/cs2.json`
2. Ви можете підключити ці JSON безпосередньо у мобілку як локальний Mock/Asset і верстати екрани одразу.
3. Опис полів та структури API описаний у `../docs/openapi.yaml`.
4. Коли бекенд підніметься, ви просто підставите `baseUrl` вашого API-сервісу.

## 📱 Основні екрани для реалізації (MVP):
1. **Home Screen**: вибір гри (Dota 2 або Counter-Strike 2).
2. **Catalog / List Screen**: список персонажів або зброї з рядком швидкого пошуку та фільтрами за ролями/типом.
3. **Detail Screen**: картка героя (характеристики, скіли, опис) або картка зброї (шкода, ціна, магазин).
