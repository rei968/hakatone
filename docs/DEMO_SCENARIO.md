# Сценарій Демонстрації (Demo Script) & Багтрекер

**Відповідальний:** ЖЕ (Team Lead + QA)  
**Таймінг пітчу:** 3–5 хвилин

---

## 🎯 Сценарій живого демо (Live Demo Script)

1. **Вступ (30 сек):**
   * Проблема: Гравцям у Dota важко відстежувати часті зміни мети та збирати актуальні білди під час драфту.
   * Рішення: Мобільний асистент **Kakatone GameGuide**, який поєднує реальну статистику OpenDota зі штучним інтелектом Claude для генерації тактик і білдів у реальному часі.

2. **Демо Мобільного застосунку (1.5 хв):**
   * **Авторизація / Splash:** Запуск Flutter-додатку.
   * **Головний екран / Мета:** Показ актуального списку мета-героїв (`GET /api/meta/dota`), індикатор «Оновлено X хв тому».
   * **Картка героя та AI-білд:** Перехід у героя (наприклад, Pudge або Juggernaut). Демонстрація аналітики та персоналізованого білда, згенерованого через Claude API (`GET /api/dota/heroes/:id`).
   * **Офлайн-режим (Фіча надійності):** Вимикаємо Wi-Fi / вмикаємо режим польоту на телефоні. Додаток продовжує працювати завдяки Hive-кешу без крашів!

3. **Демо Бекенду (1 хв):**
   * **Live Sync:** Відкриваємо адмінську дію `POST /admin/sync`.
   * Пояснюємо: «Зараз ми вручну тригеримо фоновий воркер, який забирає свіжі матчі з OpenDota та оновлює аналітику».
   * На мобілці індикатор оновлюється: «Щойно оновлено».

4. **План Б (Резервний сценарій):**
   * Якщо під час презентації падає зовнішнє OpenDota API або Claude API $\rightarrow$ бекенд автоматично віддає локальний fallback-знімок `meta.json`. Презентація не зривається за будь-яких умов!
