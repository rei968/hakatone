# План Тестування (Test Plan) & Demo QA Checklist

**Відповідальний:** Team Lead + QA  
**Мета:** Гарантувати 100% працездатність MVP перед фінальною презентацією на хакатоні.

---

## 1. Рівень 1: Тестування API (Postman / Swagger)

### 1.1 Статуси та валідація
- [ ] `GET /api/v1/games` повертає статус `200` та масив з мінімум двома іграми (`dota2`, `cs2`).
- [ ] `GET /api/v1/games/non_existing_game` повертає `404 Not Found` зі зрозумілим повідомленням про помилку.
- [ ] `GET /api/v1/games/dota2/heroes` повертає список героїв.
- [ ] Фільтрація: `GET /api/v1/games/dota2/heroes?attribute=Strength` повертає лише героїв сили.
- [ ] Пошук: `GET /api/v1/games/dota2/heroes?search=pud` повертає `Pudge`.
- [ ] `GET /api/v1/heroes/pudge` повертає деталі героя, список здібностей (`abilities`) та характеристики (`stats`).
- [ ] `GET /api/v1/games/cs2/weapons` повертає зброю CS2 з цінами, шкодою та типами.

### 1.2 Формат даних
- [ ] Усі зображення мають валідні `http`/`https` посилання (відсутність побитих картинок).
- [ ] Відсутні `null` або `undefined` у ключових полях інтерфейсу (ім'я, іконка, характеристики).

---

## 2. Рівень 2: Мобільний інтерфейс (Mobile UI/UX)

- [ ] **Splash Screen / Завантаження:** Користувач бачить індикатор завантаження або Skeleton, а не білий порожній екран.
- [ ] **Головний екран:** Чіткий перемикач між Dota 2 та CS2.
- [ ] **Сітка / Каталог:** Скрол плавний (60 fps), картинки не скачуть при завантаженні (налаштований Aspect Ratio / Placeholder).
- [ ] **Пошуковий рядок:** Працює пошук при введенні тексту (реакція без зависань).
- [ ] **Картка героя/зброї:** Текст вміщується на малих екранах (без помилок переповнення на зразок RenderFlex overflow).
- [ ] **Темна тема:** Гармонійний контраст кольорів відповідно до ігрової стилістики.

---

## 3. Рівень 3: Відмовостійкість (Chaos & Offline Testing)

- [ ] **Режим польоту (Airplane mode):** Якщо зникає інтернет після відкриття застосунку, дані беруться з кешу (або показується акуратна плашка "Немає зв'язку, показано збережені дані").
- [ ] **Сервер недоступний:** Застосунок не крашиться, показує кнопку "Спробувати знову" (Retry).

---

## 4. Фінальний Demo Checklist перед суддями (5 хв до пітчу)

- [ ] Сервер бекенду запущений і доступний через локальну мережу / тунель (ngrok / localtunnel / хмару).
- [ ] Мобільний застосунок зібраний у релізному або стабільному debug-білді на фізичному телефоні чи емуляторі.
- [ ] Підготовлено клікабельний "Happy Path" сценарій (початок $\rightarrow$ вибір Dota 2 $\rightarrow$ перегляд Pudge $\rightarrow$ показ здібностей $\rightarrow$ перехід до CS2 $\rightarrow$ перегляд AK-47).
